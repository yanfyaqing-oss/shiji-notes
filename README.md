# 拾记

一个轻量的学习与工作记录工具，用来把问题、思考过程和最终结果放在一起。

## 使用

直接打开 `index.html` 可以使用核心功能。为了启用离线缓存与“安装到桌面”，请通过本地静态服务器打开：

```powershell
python -m http.server 8000
```

然后在电脑访问 `http://localhost:8000`。同一 Wi-Fi 下，手机可访问电脑的局域网 IP 加端口 `8000`。

数据保存在当前浏览器的 `localStorage` 中。请在“数据与设置”里定期导出 JSON 备份；换设备时，在新设备导入备份即可。

## 功能

- 按问题、过程、结果的结构记录
- 搜索、状态筛选、分类筛选、标签和置顶
- 本地自动保存，无需账号和服务器
- JSON 备份导入与导出
- 深色模式、手机响应式界面
- PWA 安装与离线使用
